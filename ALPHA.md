# Kora Framework is in alpha

Kora Framework and its resources are a work in progress. APIs, configuration,
and behavior may change, and some features may be incomplete or unstable. Do not
assume this software is ready for production use.

Trying Kora? We welcome feedback, bug reports, and contributions. Please share
what worked, what did not, and the steps to reproduce any issue in this
repository's GitHub Issues. Review the repository's contribution guide before
opening a pull request.
